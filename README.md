# Ruang Belajar — Kepemimpinan & Komunikasi

Panduan belajar web untuk empat soal esai UTS Kepemimpinan dan Komunikasi Interpersonal, UMS, gasal 2025/2026.

## Isi halaman

- Bedah empat soal: memimpin diri, keputusan saat konflik, kerja tim organisasi mahasiswa, dan tim multidisiplin.
- Kerangka jawaban, contoh paragraf, dan contoh tindakan yang dapat dikembangkan.
- Latihan refleksi interaktif dan navigasi soal yang mengikuti posisi baca.
- Template STAR untuk membantu menjawab bagian pengalaman nyata tanpa mengarang pengalaman pribadi.
- Tampilan responsif, dukungan reduced motion, akses lompat ke konten, dan stylesheet cetak.

## Jalankan lokal

Proyek ini memakai HTML, CSS, dan JavaScript tanpa proses build atau dependensi.

```bash
python -m http.server 4173
```

Buka `http://localhost:4173`.
